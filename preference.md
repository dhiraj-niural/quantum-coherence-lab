# Project conventions

Start with README.md; read individual modules as needed.

- Keep the simulation reproducible with Python’s standard library. Media tooling is optional and documented separately.
- State gate order, bit order, seeds and numerical tolerances explicitly.
- Check exact probabilities before sampling or visualization; retain independent reference checks.
- Explain the question and measurement before introducing terminology. A reader with basic algebra and a little Python should be able to reproduce the example.
- Distinguish ideal simulation, hardware evidence and novel research. Cite relevant sources and record review dates.
- Keep modules focused and documentation current. Preserve numerical evidence when refactoring.
